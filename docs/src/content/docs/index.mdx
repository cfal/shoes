Shoes reads YAML configuration files. Start with a local SOCKS5 listener, then add upstream clients, routing, or transparent capture as needed.

- [Installation](/start/installation/) and [first configuration](/start/first-config/): run and validate a local listener.
- [Configuration model](/start/configuration-model/): understand entries, groups, and files.
- [Examples](/start/examples/): copy complete YAML from the source tree.
- [Server](/config/server/) and [client](/config/client/): shared fields and transport settings.
- [Protocols](/protocols/socks5/): server and client settings by protocol.
- [Rules](/routing/rules/), [DNS](/dns/configuration/), and [TUN](/config/tun/): traffic handling.

This reference documents the source revision shown above. Development documentation can include features that are not yet available in a released binary.
