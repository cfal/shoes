# Shoes Configuration

The configuration reference now lives in the [Shoes documentation site](https://shoes-rs.github.io/). Its [source pages](docs/src/content/docs/) are maintained with the parser, validator, and [example YAML files](examples/) in this repository.

- [First configuration](https://shoes-rs.github.io/start/first-config/)
- [Configuration model](https://shoes-rs.github.io/start/configuration-model/)
- [Global settings](https://shoes-rs.github.io/config/global-settings/)
- [Server](https://shoes-rs.github.io/config/server/), [client](https://shoes-rs.github.io/config/client/), and [TUN](https://shoes-rs.github.io/config/tun/) configuration
- [Protocol reference](https://shoes-rs.github.io/protocols/socks5/)
- [Routing](https://shoes-rs.github.io/routing/rules/), [DNS](https://shoes-rs.github.io/dns/configuration/), and [certificates](https://shoes-rs.github.io/security/certificates/)
- [CLI and validation](https://shoes-rs.github.io/operations/cli/)

For any given documentation build, use the version label and source revision shown on the site's first page. The source tree's `master` branch may describe unreleased behavior.
